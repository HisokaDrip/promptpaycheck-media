# promptpaycheck-media

Public files for [@thepromptpaycheck](https://www.instagram.com/thepromptpaycheck/), served by GitHub Pages.

- `index.html` + `prompts.json`: the free prompt page (link in bio). The bot adds each new reel's prompt to `prompts.json`; hand edits are kept.
- `assets/`: page images and fonts (Anton, Inter, JetBrains Mono, SIL Open Font License, see `assets/fonts/LICENSE-*.txt`).
- Dated folders: reel and carousel media for Instagram to fetch. Folders older than 7 days are removed automatically.
